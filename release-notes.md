# v1.0.0 — Japanese narration / 日本語ナレーション

One workflow switches Irodori and Qwen3-TTS, with AI/manual control, character menus, reading review and local reading memory. / 1本のワークフローでIrodori・Qwen3-TTS、AI/手動、声キャラ、読み確認とローカル記憶を切り替えます。

After installation, click Download models in the generation node. / 導入後、音声生成ノードの「必須モデル一式を取得」を押します。

The ZIP contains the workflow, custom node, installer and documentation; models and personal data are excluded. / ZIPはワークフロー・カスタムノード・導入処理・説明書を同梱し、モデルと個人データは含みません。

Real GPU runs verified Irodori, Qwen presets/reference, automatic selection and pronunciation review. ZIP manifest and clean-tag rebuild were checked. / Irodori・Qwen既定話者と参照・自動選択・読み確認を実GPUで検証。ZIPマニフェストとクリーンなタグからの再構築を確認。

Linux/WSL2 + NVIDIA CUDA + existing ComfyUI. Fresh installation on another PC is not verified; see README. / Linux・WSL2、NVIDIA CUDA、導入済みComfyUIが対象。別PCへの新規導入は未検証です。READMEをご覧ください。
